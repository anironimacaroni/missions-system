# מרחב - ניהול משימות עם סוכן AI

מערכת אישית לניהול משימות בעברית (RTL), מחולקת למרחבים. כל מרחב נפתח בתצוגה שנבחרה לו (קנבן, רשימת TODO או לוח שנה), ובצד המסך יושב סוכן AI שקורא, מוסיף, מעדכן, מוחק ומסכם משימות.

## מה יש בפנים

- **דשבורד**: בחירת מרחבים (נשמרת), רשימות "דחוף / להיום / באיחור", וכרטיס סיכום לכל מרחב.
- **מרחבים**: צבע, שם ותצוגה לכל מרחב. אפשר להחליף תצוגה בכל רגע.
- **קנבן** (גרירה בין עמודות), **רשימת TODO** (ממוינת לפי עדיפות, וי = הושלמה), **לוח שנה** חודשי (לחיצה על יום יוצרת משימה בתאריך הזה, גרירה מזיזה תאריך).
- **סוכן**: צ'אט צף עם 5 כלים (`read_tasks`, `add_tasks`, `update_tasks`, `delete_tasks`, `summarize_tasks`). פועל רק על הבחירה הנוכחית (מרחב אחד או כולם). פעולה על יותר מ-3 משימות או מחיקה מחכה לאישור בכפתורים, והאכיפה נעשית בשרת.
- **כניסה**: סיסמה אחת (`APP_PASSWORD`).

## הרצה מקומית

```bash
npm install
cp .env.example .env     # ולמלא את הערכים
npm run seed             # נתוני דוגמה (רק אם המסד ריק)
npm run dev
```

## משתני סביבה

| משתנה | תיאור |
| --- | --- |
| `DATABASE_URL` | חיבור ל-Postgres. הטבלאות נוצרות אוטומטית בבקשה הראשונה |
| `OPENAI_API_KEY` | מפתח OpenAI לסוכן |
| `APP_PASSWORD` | הסיסמה לכניסה למערכת |
| `OPENAI_MODEL` | אופציונלי. ברירת מחדל `gpt-6-luna` (תחילית `openai/` מוסרת אוטומטית) |
| `OPENAI_BASE_URL` | אופציונלי. כתובת בסיס אחרת ל-API תואם OpenAI |

## מבנה

```
src/app            דפים ונתיבי API (Next.js App Router)
src/components     ממשק: דשבורד, תצוגות, כרטיס משימה, צ'אט
src/lib            מסד נתונים, אימות, תאריכים, והסוכן (lib/agent)
scripts/seed.ts    נתוני דוגמה
scripts/dev        שרת OpenAI מדומה לבדיקות מקומיות
```
